# Дневник тренировок

HTML-приложение по программе тренировок: выбираешь тренировку → видишь все упражнения,
жмёшь на название → открывается видео с техникой на YouTube. Внизу каждого упражнения —
поля для веса и повторов по подходам. Дата тренировки выбирается сверху. Дневник
хранится в облаке (Firebase) и синхронизируется между телефоном и компьютером.

Оптимизировано под мобильный, отлично работает и на компьютере.

## Что внутри
| Файл | Назначение |
|------|-----------|
| `index.html` | разметка приложения |
| `styles.css` | стили (мобильная тёмная тема) |
| `app.js` | логика: выбор тренировки, ввод веса/повторов, синхронизация |
| `data.js` | все 17 тренировок + ссылки на видео (сгенерировано из PDF) |
| `firebase-config.js` | **сюда вставить конфиг Firebase** |

Без настройки Firebase приложение работает как справочник (видео + программа), но
дневник не сохраняется. Чтобы включить сохранение с синхронизацией — 5 минут настройки ниже.

---

## Шаг 1. Настройка Firebase (для дневника с синхронизацией)

1. Открой <https://console.firebase.google.com> и войди своим Google-аккаунтом.
2. **Add project** → назови, например, `workout-log` → создавай (Google Analytics можно выключить).
3. В проекте нажми иконку **`</>`** (Web) → зарегистрируй приложение (любое имя) →
   Firebase покажет объект `firebaseConfig`. **Скопируй его значения.**
4. Вставь их в файл `firebase-config.js` вместо заглушек `ВСТАВЬ...` и сохрани.
5. Слева **Build → Firestore Database → Create database** → выбери регион (ближайший,
   например `eur3`) → запусти в **Production mode**.
6. Вкладка **Rules** в Firestore — вставь эти правила и нажми **Publish**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```
   (каждый видит только свои данные)
7. Слева **Build → Authentication → Get started** → вкладка **Sign-in method** →
   включи провайдер **Google** → Save.
8. **Authentication → Settings → Authorized domains → Add domain** — добавь домен,
   на котором будет сайт: `ТВОЙ_ЛОГИН.github.io` (например `jybronto.github.io`).
   Без этого вход через Google на GitHub Pages не сработает.

Готово. Открой сайт, нажми **«Войти»** → войди через Google. Теперь дневник
сохраняется автоматически и открывается с любого устройства под тем же аккаунтом.

> Конфиг Firebase (`firebase-config.js`) — **не секрет**, его можно спокойно держать
> в публичном репозитории. Доступ к данным защищают правила Firestore и список
> авторизованных доменов, а не ключ.

---

## Шаг 2. Хостинг на GitHub Pages

Если репозиторий уже создан и запушен, включи Pages:

1. Репозиторий на GitHub → **Settings → Pages**.
2. **Source: Deploy from a branch**, **Branch: `main`**, папка **`/ (root)`** → Save.
3. Через ~1 минуту сайт будет доступен по адресу
   `https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`.
4. Добавь этот домен в Authorized domains Firebase (Шаг 1.8), если ещё не добавил.

Обновление после правок:
```bash
git add -A && git commit -m "update" && git push
```

## Как пользоваться
- **Список тренировок** → нажми на нужную.
- **Название упражнения** (синее, «▶ видео») → откроется техника на YouTube.
- **Дата** сверху — по умолчанию сегодня; можно выбрать прошлую тренировку и заполнить/поправить.
- **вес × повт.** для каждого подхода; **«+ подход»** добавляет строку, **✕** удаляет.
- Под упражнением показывается **«Прошлый раз»** — веса с предыдущей такой тренировки (для прогрессии).
- Всё сохраняется само; кнопка **«Сохранить»** внизу дублирует сохранение.
- **«?»** вверху — расшифровка обозначений (Р, ЗДО, дропсет, суперсет).
